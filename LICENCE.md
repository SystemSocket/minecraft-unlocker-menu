## ✨ Features

### ESP
- Waypoint Manager — set and navigate to custom waypoints
- Hitbox Viewer — visualize entity hitboxes
- Seed Map Notes — record and review world seeds
- Tick Rate Adjuster — adjust client tick rate for study (0.5x to 5x)

### Wallhack
- Skin Catalog — browse and organize player skins
- Custom Capes Notes — organize cosmetic capes
- Block Highlight — improved block visibility with outline

### Aimbot
- Inventory Sorter — organize inventory with one key
- Crafting Planner — plan recipes and resources
- Chunk Borders — toggle chunk boundary display
